# Reference: facts to look up

The reader knows what they want and needs an exact answer: a command, a flag,
a config key, an exit code. Describe; do not instruct.

Belongs:
- A one-paragraph summary of what is described.
- Every item, in a consistent shape (a table or one heading each): name, what
  it is, accepted values, default.
- Facts taken from the code or `--help`, not from memory.

Does not belong:
- Steps or advice ("first do X"); that is a how-to.
- Reasons and history; that is an explanation.
- Anything that is not true of the current version.
