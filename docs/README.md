# Documentation

Pages for people who use this project, one folder per Diataxis type
(tutorials, how-to, reference, explanation). Each page is listed here.
- [Get started with kmctl](tutorials/get-started-with-kmctl.md): Set a repository up, record a first decision and check it, in one sitting.
- [Install the plugin and the CI action](how-to/install-the-plugin-and-the-ci-action.md): Add the Claude Code plugin and the GitHub Action to a repository, with the opt-in audit.
- [Commands](reference/commands.md): Every kmctl command, subcommand and option.
- [Why one hook and report-only audits](explanation/why-one-hook-and-report-only-audits.md): Why the session briefing is the only hook and why audits only report.
- [Where kmctl fits in knowledge management](explanation/where-kmctl-fits-in-knowledge-management.md): The problems kmctl solves, the kinds of agent memory, and what it leaves to a shared layer above the repository.
