# How-to: one task, one way

The reader already knows the basics and has a goal. Get them there.

Belongs:
- The task in the title, as the reader would say it ("Install the plugin for every repository").
- What must be true before they start.
- The steps, in order, with the exact commands.
- How to check it worked.

Does not belong:
- Teaching the basics; link the tutorial.
- Why it works; link the explanation.
- A full list of options; link the reference.
- Several tasks: one page per task.
