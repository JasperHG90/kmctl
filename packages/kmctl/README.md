# kmctl

kmctl keeps a repository's knowledge current: `docs/` for people who use a
project, an `.okf/` knowledge bundle for people and agents working on it, and
skills and rules for procedure.

kmctl lives in the kmctl repository as a package of its own, beside
`packages/kmaudit`. The repository's
[README](https://github.com/JasperHG90/kmctl#readme) and
[docs](https://github.com/JasperHG90/kmctl/tree/main/docs) explain how to
install and use it.
